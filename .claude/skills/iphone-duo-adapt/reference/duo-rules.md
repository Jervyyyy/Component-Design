## 2. 必须遵守的规则

- **标题栏**：头部总高 84（上 24 + 本体 48 + 下 12），标题左对齐紧跟返回按钮，左侧按钮距边 = 页边距（最小 20）；始终在顶部；始终避让 VB / Reserved Region；分栏时只覆盖主栏。
- **全局导航**（首页 + 底部 5 个频道页的 TabBar）：系统控件，按系统尺寸/方向显示（可能变成右侧竖排），稿中只示意。
- **内容区底部栏**：同直板机，高 49 + Home Indicator 34，贴所属区域底部，宽度跟随可用区域（不进 VB）。
- **安全区**：外屏、内屏横屏有 VB；内屏竖屏无 VB、内容撑满。一级页在内屏横屏**必须**避让 VB。
- **VB 处理二选一且外屏 = 内屏横屏**：方式 B「内容避让、背景延伸到 VB 下」或方式 A「整体避让、VB 置白」。
- **版心断点**（W = 窗口宽）：W<600 → 20/20；600–834 → 卡片 24 / 通栏 32；834–1184 → 32/40；≥1184 → 版心 1120 居中。简化方案：全部沿用 20。
- **只加宽不放大**：控件、图标、文字保持直板机尺寸；媒体（图片、视频）可放大。
- **窄卡片图片**：卡片宽 < 340（如内屏竖屏双列）→ 卡内图片 3:4、高度保持直板机高度；≥ 340 保持原比例。
- **浮层 Sheet**：W<834 左右各 8；W≥834 最大宽 653 居中；页面不开避让时按浮层顶距 250 判定是否避让 VB。
- **底部提示条**：宽 = min(版心 − 16, 400)，距底部栏 12 或距窗口底 34。
- **对话框**：TDS 默认宽度不拉伸，遮罩铺满；外屏在内容区内对齐，内屏整屏居中。
- **组件不进入 VB、不跨折痕；分栏时标题栏/底栏只出现一次；开合旋转保持状态。**

浮层、提示条、对话框、视频、OCR、广告 Banner 等脚本**不会自动处理**——在方案说明和适配说明里写清楚规则，提醒设计师手动调整。

## 3. 方案决策表（推荐 → 备选按开发难度降级）

先按 analyze 结果判定 `pageType`（有 TabBar = primary）、`layoutType`（card / fullBleed）、`hasBottomBar`，再看内容模式：

| 内容模式（analyze 线索） | 02 内屏竖屏 推荐 | 03 内屏横屏 推荐 | 备选（降级，通常是通栏） | 开发成本 |
|---|---|---|---|---|
| 重复卡片列表（`repeatGroups` 里同构卡片 ≥ 2） | `grid` 2 列（列宽 < 340 时图片 3:4） | `grid` 2 列（尽量保证列宽 ≥ 340）；卡片很窄才 3 列 | 单列拉伸到版心 | 推荐：中 / 备选：低 |
| 一组 2–3 个并列对比项（A vs B） | 对比项并排 `grid` 2 列 | 同左，或并入分栏次栏 | 单列 | 中 / 低 |
| 主内容 + 辅助信息（攻略/对比/详情 + 推荐/追问/快捷入口） | 单栏 + 局部网格 | `split` Main–Support：主栏放主内容，`secondaryIds` 放辅助块 | 全宽单栏 | 高 / 低 |
| 纯列表页（点进详情） | 单栏 | `split` List–Detail，需要设计师给详情页 `detailSourceId`；没有详情稿就退回全宽单栏 | 全宽单栏 | 高 / 低 |
| 横滑模块（`kind: hscroll`） | 不改，宽度变大露出更多项 | 同左 | 同左 | 低 |
| 通栏大图 / Banner（`kind: media`） | 安全区裁切（手动） | 同左 | 等比放大有上限、居中 | 中 / 低 |
| 表单 / 流程 / 设置页 | 单栏，按断点边距 | 单栏；表单不做网格 | 单栏 + 简化边距 20 | 低 |

VB：推荐行外屏、内屏横屏都用 `vb: "B"`，备选行都用 `vb: "A"`（规范要求同一 App 两者一致）。
外屏 01 推荐与备选通常只差 VB 方式——外屏宽 382，不做网格。

## 4. 待确认项（不要自行编造数值）

1. VB / Reserved Region 精确尺寸以系统安全区为准（稿中按 84 / 151×84）。
2. 「窗口宽度」是否含 VB（目前按内容区宽取边距；外屏、内屏横屏两种算法落在同一档，结果一致）。
3. 浮层「距顶 250」是否适用于页面开启避让的场景；边界是 ≤250 还是 <250。
4. 头图广告位的安全区宽度、统一展示高度。
